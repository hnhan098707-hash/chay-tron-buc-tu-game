# Chạy Trốn Bức Tử

Game platformer pixel-art viết bằng Python và Pygame.

## Chạy từ mã nguồn

1. Cài Python 3.10 trở lên.
2. Cài Pygame:

   ```powershell
   py -m pip install -r requirements.txt
   ```

3. Chạy game:

   ```powershell
   py chay_tron_buc_tu_plus.py
   ```

## Điều khiển

- `Space` / `W` / `↑`: nhảy; nhấn lần nữa để nhảy đôi.
- `J` / chuột trái: bắn.
- `P` / `Esc`: tạm dừng.
- `F11`: bật/tắt toàn màn hình.
- `R`: chơi lại sau khi kết thúc.

Game có các chế độ Sinh tồn, Thử thách 90 giây và Săn quái. Cài đặt được lưu vào `cai_dat.json` cạnh chương trình khi chạy.
